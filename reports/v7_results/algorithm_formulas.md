# V7 原型算法、公式与适用边界

## 1. 已知自由区 Gateway

网格自由集合为 `F={(y,x): occ[y,x]<-0.6 且 clearance[y,x]>=16px}`，未知集合为 `U={-0.6<=occ<=1.0}`。候选网关 `G={c∈F: c 的四邻域至少有一个未知单元}`。本机与网关之间运行有界八邻域 A*，每条边仍在 `F`，对角边要求两个正交侧单元也在 `F`，避免穿过墙角。`own_evidence` 与融合地图冲突只产生重新观察需求，不会直接把障碍改为自由。

起点接线必须同时通过本机实时 LiDAR 和已知自由地图。运行时每个航点分段再次检查；只有实际距离网关小于 16px 且航点索引到末端，才记为 `reached`。计划成功不代表导航成功。

## 2. 短距未知探查与 35 射线

在网关处，对朝向前方最近的 3 条有效 LiDAR 射线取最小测距 `d_min`。一次建议长度 `min(8px, d_min-r_body-5px)`；小于 3px 则拒绝。相同网关连续 3 帧通过后才允许下一短段，已知占据栅格与边界永久禁止进入。此判据只是局部可行性代理，仍须由正式控制安全层过滤。

官方 `compute_ray_angles(2π,35)` 两端方向重复，有效相邻角间距 `Δ=2π/34`。三相位补扫角为 `Δ/3≈0.0616rad`。仅在新站位实际到达后可执行；不会把旋转或 LiDAR 空间当作炸弹不存在的证明。

## 3. 无 GPS 的本机短退路

里程计 `(d,α,Δθ)` 的一次更新为 `x'=x+d cos(θ+α)`、`y'=y+d sin(θ+α)`、`θ'=wrap(θ+Δθ)`。轨迹原点任意，不和全局图绑定。候选旧路点距当前 9–28px、历史年龄不超过 135 帧；保守漂移代理 `σ≈√age·σ_d+distance·σ_θ·√age` 要小于 15px。实时 LiDAR、机体与 PivotJoint 载荷摆动包络必须验证局部短段。模型只能支持局部撤离，不能证明无 GPS 全程返航。

## 4. 空载制动只读模型

随包 `v7_brake_shadow.py` 保留空载标定 `v[k+1]=0.95v[k]+0.5729312289729012u[k]`，可根据净空上界估计允许速度。这一模型没有替代原飞控，更未用于 PivotJoint 载弹控制。当前官方消融重点是可执行网关与 GPS 失效短退路，制动模块没有动作接管。

## 5. 接收判据

接收主动功能必须在相同固定布局与引擎种子下增加实际到达与合法观测，并且官方处置数不下降；原满拆地图要全部守住。若增加抓取却减少处置，也判定失败。当前 Map08 Gateway 掉弹，Map09 退路没有改善处置且健康/分数下降，两个主动功能都拒绝默认启用。稳定提交包不变。
